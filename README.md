# 🎓 Website Kelas XII PPLG 3 — SMK Negeri 1 Beringin
### Digital Yearbook & Class Portal (Angkatan 2026)

Website resmi kelas XII PPLG 3 SMK Negeri 1 Beringin (Pengembangan Perangkat Lunak dan Gim) Angkatan 2026.

---

## ✨ Fitur Utama

1. **Floating Island Navbar:** Navbar modern yang bersembunyi otomatis saat scroll ke bawah dan muncul kembali saat scroll ke atas.
2. **Atmospheric Hero Section:** Integrasi foto kebersamaan kelas dengan efek blending dan tipografi modern.
3. **Kisah & Kebersamaan:** Catatan perjalanan tiga tahun bersama Wali Kelas Ibu **Vevy Sisnia, S.Kom.**
4. **Running Ribbon Marquee:** Banner nama seluruh 31 siswa yang berjalan dua arah (*dual marquee*).
5. **Direktori 31 Siswa Asli:**
   - Foto resmi siswa berlatar merah yang telah di-crop proporsional terpusat pada wajah.
   - Pencarian real-time berdasarkan nama dan akun Instagram.
   - Tautan langsung ke profil Instagram setiap siswa.
   - Modal detail interaktif yang responsif dan mudah ditutup (klik backdrop / tombol Esc).
6. **Galeri Dokumentasi:** Galeri foto multi-kolom dengan parallax scroll alami berkecepatan dinamis.
7. **Catatan & Kenangan:** Dinding pesan interaktif dari guru dan perwakilan siswa.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animation:** GSAP (GreenSock) + ScrollTrigger + `@gsap/react`
- **Smooth Scroll:** Lenis Smooth Scroll
- **Icons:** Lucide React

---

## 🚀 Cara Menjalankan Project

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Mode Development
```bash
npm run dev
```
Buka browser di [http://localhost:3000](http://localhost:3000).

### 3. Build & Jalankan Mode Produksi
```bash
npm run build
npm run start
```
